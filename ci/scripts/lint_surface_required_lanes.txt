# Required merge-path clippy lanes — read by `check_lint_surface_closure.py`.
#
# That gate's closure half derives obligations from `cargo metadata`: a target
# with `required-features` must be covered by some merge-path
# `cargo clippy -D warnings` lane. It cannot see code gated by a `#[cfg(feature
# = ...)]` inside a target that needs no feature (a `live-gpu-tests` test in a
# lib, an `unprivileged-tests` test in `it`). This registry names those
# surfaces: each row must be matched by a merge-path lane, so deleting the lane
# reddens the gate naming the row.
#
# Format, one lane per line, whitespace-separated:
#
#     <crate>  <feature-set>  <target-selection>
#
#   crate            a workspace package; the lane must scope to it (`-p
#                    <crate>`, or `--workspace` without `--exclude <crate>`).
#   feature-set      comma-separated features the lane must activate, resolved
#                    through the crate's own `[features]` implications; `-` for
#                    none. `!name` forbids a feature: a surface gated on
#                    `not(feature = "name")` needs a lane without it.
#                    `--all-features` satisfies every positive row and fails
#                    every negated one.
#   target-selection one of `all-targets`, `tests`, `bins`, `lib`, `examples`,
#                    `benches`; `--all-targets` on the lane satisfies any.
#
# Only a lane that denies warnings counts, and only in a job that runs on every
# pull request touching the row's crate. An empty or missing registry is a FAIL.
