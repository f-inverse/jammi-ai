# check_no_consumer_names.py waiver allowlist — mirrors the self-rotting-
# waiver idiom of arch_validation_freshness_allowlist.txt.
#
# The governance-verb tripwire and the leak-smell scan are advisory: a
# generic pattern match, not a proven violation. A finding a maintainer has
# ruled MECHANISM (not governance; no consumer name) must not be forced into
# renaming a correct identifier to dodge the grep. This file is the annotate
# path: a reviewed ruling lands in the tree, and a waived finding
# still PRINTS (as an informational line naming this row and its ruling) so
# it stays visible in every CI log — silence is how a waiver becomes
# invisible.
#
# Format: one row per line, five TAB-delimited fields (a literal TAB
# character between each — not spaces):
#
#   <identifier><TAB><declaring_path><TAB><ruling_sha><TAB><ruling_ref><TAB><reason>
#
#   - identifier      the exact public identifier the tripwire/leak-smell
#                      scan flagged (e.g. `register_read_view`).
#   - declaring_path  the repo-relative path where `identifier` is publicly
#                      declared. Scoping is PER (identifier, declaring_path)
#                      PAIR — a second site with the same identifier name
#                      needs its OWN row; one row can never amnesty a class.
#   - ruling_sha      a 40-hex commit sha, an ANCESTOR of HEAD, at which the
#                      ruling below was made.
#   - ruling_ref      a resolvable citation carrying the verdict: either a
#                      `<doc-path>#<heading>` pair (the heading text must
#                      appear in that doc) or a bare issue/PR number (`#123`).
#   - reason          ONE sentence, in MECHANISM vocabulary, naming what
#                      state the identifier changes. Must not itself lead
#                      with a governance-verb stem as its main verb (that
#                      would just restate the tripwire, not resolve it),
#                      must not be a bare line-number citation, and must not
#                      be trivially short.
#
# Rot, re-verified on EVERY run, every one a hard FAIL (never a soft skip):
#
#   1. `identifier` no longer matches a public declaration in
#      `declaring_path` — a rename must re-earn its ruling.
#   2. `declaring_path` is missing.
#   3. `ruling_sha` is malformed, or is not an ancestor of HEAD.
#   4. `ruling_ref` does not resolve.
#   5. `identifier` appears nowhere in the crates tree at all — a DEAD
#      waiver; delete the row.
#   6. `reason` is trivially short, is itself phrased with a governance verb
#      as its main verb, or carries a bare line-number citation instead of
#      a mechanism sentence.
#   7. A row waives `identifier` and `declaring_path` as a PAIR, never
#      `identifier` alone — a second site with the same identifier needs
#      its own row (enforced by construction: matching is always by the
#      exact pair, and a duplicate pair is itself a hard fail at load time).
#
