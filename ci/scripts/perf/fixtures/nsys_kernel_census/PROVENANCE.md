# Provenance — `nsys_kernel_census/` fixtures

`profile_421_legs.sh`'s `LORA_BIAS_AB_DRY_RUN`/`PROFILE_421_LEGS_DRY_RUN`
stub for `nsys export` copies a real sqlite export to the export path
(never touch-empties it), so `kernel_census.py` runs its real query/
domain-check machinery — gated behind the `run_cmd` no-op under
DRY_RUN — against real (if synthetic) kernel rows in every hermetic
dry run. `n.sqlite`/`m.sqlite` here are that real, schema-valid nsys
sqlite export pair: the same `CUPTI_ACTIVITY_KIND_KERNEL` joined to
`StringIds` on BOTH `shortName` and `demangledName` (the real nsys
2025.3.2 export shape `kernel_census.py`'s own query requires), plus
empty `CUPTI_ACTIVITY_KIND_MEMCPY`/`CUPTI_ACTIVITY_KIND_MEMSET` tables,
that a real nsys `export --type=sqlite` produces.

Generated byte-for-byte by the committed `gen_nsys_kernel_fixture.py` in
this directory — deterministic (no RNG, no wall-clock read): one fixed
kernel (`shortName="fixture_attention_block_kernel"`, `demangledName=
"void jammi_kernels::fixture_attention_block_kernel(float const*,
float*)"`) at grid `(1,1,1)`/block `(32,1,1)`, launches back-to-back at a
fixed 1000ns duration each, launch COUNT the only knob. Regenerate with:

```
python3 ci/scripts/perf/fixtures/nsys_kernel_census/gen_nsys_kernel_fixture.py \
    --launches 5  --out ci/scripts/perf/fixtures/nsys_kernel_census/n.sqlite
python3 ci/scripts/perf/fixtures/nsys_kernel_census/gen_nsys_kernel_fixture.py \
    --launches 30 --out ci/scripts/perf/fixtures/nsys_kernel_census/m.sqlite
```

`n.sqlite` (5 launches) / `m.sqlite` (30 launches) give `kernel_census.py`'s
`build_report` a genuine POSITIVE launch-count delta (`dn=25`) on the one
kernel bucket present — enough to clear `EmptyDifferencedCensusError`
(at least one bucket must carry real added work) without tripping any
negative-delta or fixed-cost-jitter guard; the generator's own
`--self-test` arm asserts exactly this against the real
`kernel_census.build_report`, AND asserts the freshly-built bytes are
byte-identical to these two committed files — wired into
`.github/workflows/ci.yml` ("perf nsys kernel fixture self-test"), so a
generator edit that forgets to regenerate these files fails CI rather
than shipping a silently stale fixture. Total fixture size is ~40KB
(well under the 100KB budget) — both files are sqlite's own minimum
on-disk page size for a handful of rows, not a designed-in bloat.
